# CMA Fitness Solutions Website — Version 3.3

Version 3 retains the full scrolling website and introduces:

- The supplied CMA Fitness logo in the header, hero and footer
- A prominent hero logo panel
- Bronze-gold accent colours matched more closely to the logo
- Four benefit panels beneath the landing area
- Five core feature panels
- Three automatic screenshot positions
- Personal and Trainer edition panels
- Edition comparison, FAQ, Microsoft Store, support and legal sections
- Responsive mobile navigation

## Install over the current GitHub Pages website

1. Extract this ZIP to a temporary folder.
2. Copy everything inside the extracted folder into:

   C:\Users\zippy\Documents\CMA-Fitness-Website

3. Choose **Replace the files in the destination**.
4. Open GitHub Desktop.
5. Commit with:

   Upgrade website to Version 3

6. Click **Push origin**.

## Application screenshots

Add these exact filenames to the `images` folder:

- `dashboard.png`
- `training.png`
- `nutrition.png`

The website will detect and display them automatically.
